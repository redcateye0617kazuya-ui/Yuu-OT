隱私權政策

最後更新日期：2026 年 11 月

呢個網站（下稱「本網站」／「本 Dashboard」）係一個非商業性質嘅個人工具，用嚟記錄同顯示一個 YouTube 直播加班馬拉松活動入面嘅課金（SuperChat／PayMe）、送會員、留言板留言等資訊，俾參與活動嘅直播觀眾同台主本人使用。本頁解釋本網站會收集咩資料、點樣使用、同埋點樣保護呢啲資料。

我哋收集嘅資料

  • YouTube 直播聊天室資料（透過 YouTube Data API 讀取）：SuperChat 課金嘅顯示名稱、金額、留言內容；送會員、會員里程碑留言、新／升級會員事件嘅顯示名稱同相關資訊。呢啲資料本身已經係 YouTube 直播聊天室入面公開可見嘅內容。
  • 人手輸入資料：PayMe 課金嘅用戶名同金額，由直播操作者人手輸入（因為 PayMe 冇公開 API）。
  • 留言板留言：觀眾自願喺本網站留言板輸入嘅暱稱同留言文字。

本網站唔會收集密碼、付款卡資料、地址等敏感個人資料，亦都冇用戶登入系統。

點樣使用呢啲資料

  • 計算同顯示本場／全馬拉松累積課金總額
  • 顯示金主榜（捐款排行榜）
  • 根據預先設定嘅規則計算加班／加鐘時數
  • 喺直播記錄（Record）頁面保留每場直播嘅課金明細，方便覆查

呢個 Dashboard 本身就係直播活動公開展示嘅一部分，上述資料（例如金主榜、課金記錄）會公開顯示俾所有訪問本網站嘅人睇到，性質上同直播聊天室入面本身已經公開嘅課金訊息相若。

資料儲存

本網站用 Google Firebase（Firestore）作為資料儲存後台，資料儲存喺 Google 嘅伺服器上。本網站冇將資料提供俾上述以外嘅第三方作廣告或其他商業用途。

資料刪除要求

如果你出現喺本網站嘅記錄入面（例如你嘅 SuperChat／PayMe／留言），而想要求刪除你嘅資料，歡迎透過直播留言、留言板，或者直接私訊台主所屬嘅 YouTube 頻道提出，台主會盡快處理。

YouTube API Services 聲明

本網站使用 YouTube API Services（YouTube 服務條款）。繼續使用本網站涉及 YouTube API 嘅功能，即代表你同意受 YouTube 服務條款約束。你亦可以參閱 Google 隱私權政策 以了解 Google 點樣處理資料。

政策嘅更新

本政策日後如有重大改動，會喺呢頁更新並調整上面「最後更新日期」。
